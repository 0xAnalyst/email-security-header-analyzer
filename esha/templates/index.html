Finding the headers

Gmail
Open the message, choose More, then Show original.
Outlook
Open the message, choose … then View, then View message source (or File › Properties on desktop).
Apple Mail
View › Message › All Headers, or drag the message to your desktop to save an .eml.
Thunderbird
More › View Source, or press Ctrl+U.
